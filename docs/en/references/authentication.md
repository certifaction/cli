# Authentication

Document signature, revocation and getting user information require authentication.
The authentication is done by passing an authentication token or an API key:

- Access tokens can be issued by you or by an external OIDC provider. Either case, Magenta Security Sign will have to register the identity provider.
- API keys are managed from the Magenta Security Sign web application. They can only be used for server side API integration.
