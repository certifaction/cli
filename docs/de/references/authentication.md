# Authentifizierung

Dokumentsignierung, Widerrufung und das Abrufen von Benutzerinformationen erfordern eine Authentifizierung.
Die Authentifizierung erfolgt durch die Übermittlung eines Authentifizierungstokens oder eines API-Schlüssels:

- Access-Token können von Ihnen oder einem externen OIDC-Anbieter ausgestellt werden. In beiden Fällen muss Magenta Security Sign den Identitätsanbieter registrieren.
- API-Schlüssel werden über die Magenta Security Sign-Webanwendung verwaltet. Sie können nur für serverseitige API-Integration verwendet werden.
