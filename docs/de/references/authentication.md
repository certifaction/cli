# Authentifizierung

Dokumentsignierung, Widerrufung und das Abrufen von Benutzerinformationen erfordern eine Authentifizierung.
Die Authentifizierung erfolgt durch die Übermittlung eines Authentifizierungstokens oder eines API-Schlüssels:

- Access-Token können von Ihnen oder einem externen OIDC-Anbieter ausgestellt werden. In beiden Fällen muss <ProductName/> den Identitätsanbieter registrieren.
- API-Schlüssel werden über die <ProductName/>-Webanwendung verwaltet. Sie können nur für serverseitige API-Integration verwendet werden.
